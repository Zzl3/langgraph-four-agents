# AI 使用记录

初版代码、测试与文档由 Codex 根据题目生成和修改；Codex 也执行了安装、离线测试及本地 Ollama/Qwen 与 Llama 真实模型试跑。真实模型试跑使用合成输入，成功与失败均逐条记录在 `examples/outputs/real_*.json`；不能把失败记录描述为通过。Codex 根据“分别实现四题”的要求，将图工厂调整为按任务编译四个独立的任务绑定 StateGraph，并补充结构测试。`examples/http_demo` 是离线模拟服务，不是模型评测。

第二模型 GPT-6.1 Terra 按候选人视角独立只读审查了题目、代码、测试、文档和模拟/真实轨迹；根据其发现修改问答冲突判定、冲突结果归一化、规划剩余时限缺口，并新增反例测试。后续复审又发现规划状态提示与共享脚本工具契约不一致、视频修订提示未跟踪估时阶段和通过后的清除条件；Codex 据此修正并新增回归测试。审查没有启动 Ollama，也没有运行测试；修改后的测试由 Codex 本地执行。
