# AI 使用记录

## 我的工作

我阅读并提供了考核题目与统一提交要求，确定最终只提交第 1 题“素材审核与发布排期 Agent”。我根据考核的核心验收点明确了项目范围：素材审核、时段冲突处理、重复提交幂等、保存失败反馈，以及替代时段必须等待确认、不能直接发布。

在实现过程中，我进一步收敛了最初覆盖四题的项目，要求删除其余三题的实现和材料，只保留排期题；考虑到本机模型占用资源，我要求停止运行 Ollama，改用离线 mock 跑通流程。我还要求另一个 agent 以评审视角独立检查代码和相关文档，并根据评审指出的交付问题补充材料。我报告本项目实际投入约 3 小时，此时长为估算。

## AI 辅助范围

Codex 辅助完成了 LangGraph 执行循环、排期工具、结果校验、测试用例、运行示例及项目文档，并根据我的范围和约束要求进行修改。独立评审 agent 对工作树进行了只读检查，没有修改项目文件，也没有运行测试或 Ollama。

项目默认使用离线 mock。它用于验证工具流程、业务约束和失败处理，不代表真实模型决策效果。历史上曾运行本地 Qwen 模型并保存两条排期轨迹，详情见 `docs/03-evaluation.md`；这些轨迹不是本次单题收敛后的重新实测。按我的要求，收敛版本的验证没有再启动或运行 Ollama。

## 验证与个人贡献边界

27 项自动化测试由 Codex 在本地运行并记录于 `examples/test-results.txt`。我负责确定题目、范围、验收关注点和模型使用约束；代码实现、测试执行及文档整理由 Codex 辅助完成。我没有报告额外的手工代码修改或人工逐项复核，因此不把 AI agent 的评审称作人工复核。
