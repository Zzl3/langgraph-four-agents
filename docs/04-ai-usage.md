# AI 使用记录

候选人提供考核题目与统一规范，选择第 1 题，要求停用 Ollama 并使用模拟流程继续优化。Codex 辅助完成了需求拆解、LangGraph 执行循环、排期工具与校验逻辑、测试、运行记录及文档整理。实现中根据工具轨迹迭代了并发时段冲突处理、幂等保存、替代时段确认边界和最终结果来源校验。另一个 Codex agent 以候选人评审视角只读检查了收敛后的工作树；其未修改代码、未启动 Ollama，也未运行测试。

项目默认使用离线 mock。历史上曾运行本地 Qwen 模型并保存了两条排期轨迹，详见 `docs/03-evaluation.md`。当前阶段不再运行 Ollama；此后验证采用本地 mock 和自动化测试。Mock 运行记录不得描述成模型自主推理。

候选人报告实际投入时长约 3 小时（估算）。候选人负责提供考核规范、选择题目并明确停用 Ollama、采用模拟流程的要求；代码实现、测试和文档整理由 Codex 辅助完成。候选人未报告额外的个人代码修改或人工逐项复核，因此不声称有此类工作；AI agent 只读评审不等同于人工复核。
