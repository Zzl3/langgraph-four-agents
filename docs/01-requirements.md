# 需求和范围

原考核允许任选一题；本项目按用户要求覆盖四题。完整题目与验收标准见仓库根目录 `题目.txt`。

- 排期：审素材与风险，查询冲突，仅存草稿，替代硬性时间须待确认，幂等处理并明确失败。支持逐项指定日期与要求时段。
- 规划：预算与期限约束下检索、生成、估价、必要时改选并保存；保留已完成步骤及失败原因。
- 问答：对制度答案引用原文、发现冲突、无资料时说明缺口，支持上下文以及故障。
- 脚本：输出分镜和来源、估算时长、检查规则，超时重新调整；不能编造事实。

统一成功标准还包含真实模型驱动工具观察与后续决策、至少两条真实决策路径、步数上限、三类输入和实际轨迹、可复现测试以及完整提交资料。本地 Qwen 真实模型已经验证两条排期路径；规划、问答、视频真实模型轨迹均失败，四题整体仍未达到完整成功标准。
